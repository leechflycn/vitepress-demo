# 昨晚我给 AI 助手补了哪些技能？

这篇文章记录一次 AI 助手技能库扩展复盘。

重点不是“装了多少插件”，而是：**一个长期运行的 AI Agent，应该怎样学习新技能、评估新工具，并且不把安全边界弄丢。**

## 一、先说结论

昨晚主要围绕 OpenClaw / AI Agent 的技能生态做了一轮资料学习和评估，重点关注 4 类能力：

- 安装前安全审查
- 联网搜索和资料采集
- 内容创作与多平台改写
- 视频 / 音频资料转文字

最后得出的结论很明确：

**第三方技能不能看到就装，必须先评估来源、权限、成本、隐私和对现有流程的影响。**

AI 助手越能干，越需要规则。

## 二、识别到的几个重点 Skill

### 1. Skill Vetter：安装前先做安全审查

Skill Vetter 的定位，是在安装陌生技能之前做风险检查。

它适合解决一个很现实的问题：很多 Agent 技能看起来很好用，但背后可能会读取文件、调用外部 API、修改配置，甚至影响记忆和系统规则。

所以它的价值不在于“多一个功能”，而在于建立一层安全闸门：

- 看清楚 skill 会读什么文件
- 看清楚它会不会外发数据
- 看清楚它会不会改系统配置
- 看清楚它是否会覆盖现有工具链行为

这类能力值得优先评估。

但也正因为它和安全边界相关，更不能盲装。

### 2. Tavily Search：面向 AI Agent 的联网搜索

Tavily Search 更像是给 AI Agent 准备的搜索和资料采集工具。

它的价值在于：

- 找最新资料
- 做事实核验
- 查技术文档
- 支持夜间学习和行业资料整理

对于一个长期做内容和方案的 AI 助手来说，这类搜索能力很有价值。

但它也有几个问题必须先评估：

- 是否需要 API Key
- 查询内容会不会发给第三方
- 成本如何计算
- 搜索结果质量是否稳定
- 是否比现有搜索工具更值得接入

结论是：可以评估，但不能默认接入。

### 3. Content Creator：内容生产工具要服务流程，而不是替代流程

Content Creator 这类技能通常主打内容生成、多平台改写、标题摘要、短视频脚本等。

这和博客、公众号、小红书、短视频口播这类内容流水线很贴近。

但它也容易带来一个问题：

**外部内容技能如果直接接管写作，很可能破坏原有风格、事实核验和发布规则。**

所以更合理的用法不是直接替代现有流程，而是把它当作参考：

- 学它的拆稿结构
- 学它的标题生成思路
- 学它的平台适配方法
- 但最终仍由自己的发布规则兜底

内容生产最怕“自动化越强，越像流水线废话”。

### 4. Self-Improving Agent：自我改进能力风险最高

Self-Improving Agent 这类技能听起来很诱人：自动记录错误、自动总结经验、自动优化自己的行为。

但对长期运行的个人 AI 助手来说，它也是风险最高的一类。

因为它可能会碰到：

- 长期记忆
- 行为规则
- 人格设定
- 系统提示词
- 工作流约束

如果没有严格边界，它可能会把“自我改进”变成“自作主张”。

所以这类技能只能谨慎评估，不能让它随意修改核心记忆和运行规则。

## 三、视频和音频学习能力是短板

这次学习中还发现一个很实际的短板：视频资料不一定有字幕。

如果没有字幕，就需要音频转文字能力。

因此，Whisper 这类语音转文字工具值得优先评估。

理想状态是：

- 优先抓视频标题、简介、字幕和章节
- 没有字幕时，再下载小体积音频
- 用本地转写优先，减少隐私和成本风险
- 转写后提炼 SOP、工具清单和可复现步骤

这对学习 B 站、YouTube、弱电教程、AI 工具教程都很有用。

## 四、真正要建立的是“技能评估流程”

昨晚最大的收获不是某一个具体 skill，而是建立了一个基本原则：

**任何第三方 skill、外部脚本、会影响工具链行为的组件，都必须先评估，再请示，再接入。**

默认允许做的事情：

- 搜索来源
- 阅读说明
- 查看权限
- 审计风险
- 做本地笔记
- 输出推荐意见

默认禁止做的事情：

- 擅自安装
- 擅自启用
- 擅自替换现有工具
- 擅自运行未知脚本
- 擅自上传本地文件、Token、Cookie、密钥或聊天记录

这个流程看起来麻烦，但对长期运行的 AI Agent 很重要。

因为 AI 助手不是一次性脚本，它会接触记忆、文件、账号、发布流程和自动化任务。

越是这种长期系统，越不能乱装东西。

## 五、后续优先补强方向

接下来最值得补强的能力有三类。

### 图片识别

用于识别弱电现场设备、接口、铭牌、接线方式和机柜布局。

但要求很明确：看不清就说看不清，不能硬猜。

### 视频学习

用于抓取视频标题、简介、字幕、章节，提炼 SOP 和方法论。

原则是少下载、优先字幕、控制体积。

### 文章查读和网页清洗

用于抓取技术文档、行业资料、厂商说明，清洗广告和无关内容，保留正文、表格、参数和来源链接。

这类能力能直接降低 token 成本，也能提高资料理解准确度。

## 六、给 AI 助手立规矩，比给它加能力更重要

很多人使用 AI Agent 时，第一反应是：给它装更多插件，让它能做更多事。

但长期来看，真正重要的是另一件事：

**能力增长必须配套边界增长。**

能联网，就要有来源核验。  
能读文件，就要有隐私边界。  
能发文章，就要有发布确认。  
能安装技能，就要有安全审查。  
能自我总结，就不能擅自改核心规则。

AI 助手不是越自由越好。

它应该越来越有能力，也越来越守规矩。

这才是长期可用的个人 AI Agent。
